# MediRoute frontend

This folder contains MediRoute’s Vite application and npm commands. The React pages and shared components live in the sibling `../src/` folder; they are imported directly and are not copied here.

See the [project README](../README.md) for the technology stack, full project layout, setup instructions, demo account guidance, feature status, privacy limitations, testing commands, and the FastAPI/PostgreSQL integration plan.

Run commands from this folder:

```powershell
npm ci
npm run dev
npm run lint
npm run build
```
